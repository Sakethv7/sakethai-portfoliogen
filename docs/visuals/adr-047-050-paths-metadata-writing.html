ADR-047 to 050: real addresses and search tags

Read from the top. A push builds the site. A plugin now writes one HTML file per page, with its own title and preview tags. Then a reader or a crawler asks for an address. Blue steps are new. Red steps are failures.

Exists today New or changed Failure path

Three things level 2 leaves out. First, the build already ends in an upload today, and a failed check now stops the workflow before it, so a bad data file never reaches the live site. Second, a failed script and an unknown address are different failures. The first keeps the old site. The second serves the 404 page with a true 404 status and a noindex tag, so search engines drop it. Third, an old address with a hash is rewritten in the browser only. A crawler never runs that step, so it still sees the home page for old links.
